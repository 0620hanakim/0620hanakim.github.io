청소년 데이터 리터러시 (ChatGPT 기반 연구방법 프로그램)

프로그램 구성

  • 수강료: 80,000원/인
  • 수강인원: 최소 10명 ~ 최대 15명
  • 대상: 중·고등학생(학년 무관, STEAM 관심자)
  • 기간: 4주 (주 2회 × 2시간)
  • 형식: 온·오프라인 병행, 프로젝트 기반 학습, 팀별 연구 수행

과정 내용 및 학습 목표

  • 과학적 연구 질문을 스스로 설정합니다.
  • ChatGPT를 활용해 자료 수집·정제·분석·시각화를 수행합니다.
  • 연구 결과를 논문 및 프레젠테이션 형태로 작성·발표합니다.
  • 공공 데이터 탐색·시각화, 데이터 윤리 교육 포함
  • 팀별 데이터 스토리텔링 프로젝트 및 데이터 해석 퀴즈 수행

회차별 커리큘럼

회차 주요 내용 학습 방식 비고
1회차 연구방법론 기초 이해, 연구 질문 설정 강의 + 사례 분석 참고 자료 제공
2회차 프로젝트 주제 선정 및 계획 수립 팀 활동 + 기획안 작성 조별 피드백
3회차 오픈 데이터 수집 및 ChatGPT 활용 기초 실습 중심 + 도구 안내 데이터셋 제공
4회차 데이터 정제 및 전처리 실습 Python 실습 + 토론 코드 템플릿 제공
5회차 기초 통계 분석 및 시각화 실습 라이브 실습 + 시각화 도구 Jupyter 노트북
6회차 ChatGPT를 활용한 보고서 초안 작성 프롬프트 실습 + 초안 피드백 자동화 템플릿 제공
7회차 결과 발표 자료(포스터/슬라이드) 제작 디자인 실습 + 발표 코칭 포스터 양식 제공
8회차 팀별 최종 발표 및 피드백 팀 발표 + 실시간 평가 수료증 발급

배송·교환·환불 정책
